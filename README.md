# 별빛 모험가 — 횡스크롤 RPG

메이플스토리 같은 2D 횡스크롤 RPG 감성에서 영감을 받은 오리지널 브라우저 게임입니다. 메이플스토리의 캐릭터·배경·음원 등 원본 리소스는 포함하지 않았습니다.

## 실행
- `index.html` 파일을 Chrome, Edge 등 최신 브라우저에서 열면 바로 플레이할 수 있습니다.
- 별도 설치, 서버, 라이브러리 없이 실행됩니다.

## GitHub Pages 배포
1. ZIP 압축을 풉니다.
2. 저장소 최상위 경로에 `index.html`과 `README.md`를 업로드합니다.
3. GitHub 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` / `/(root)`를 지정한 뒤 저장합니다.
5. 잠시 후 표시되는 Pages 주소로 접속합니다.

## 조작
- 이동: `A` / `D` 또는 `←` / `→`
- 점프: `Space` 또는 `↑`
- 공격: `J` 또는 `X`
- 모바일: 화면 하단의 방향키·점프·공격 버튼

## 포함 기능
- 카메라가 플레이어를 따라가는 횡스크롤 월드
- 점프 및 여러 높이의 발판
- 슬라임 몬스터, 근접 공격, 피격 및 체력
- 코인·경험치·레벨업·HP 성장
- 파티클 효과, 패럴랙스 배경, 모바일 터치 조작
